# Skill: rolf-schreibstil

Wenn du eine E-Mail für Rolf Müller (Partner MÜLLER PAPARIS AG, Zürich) entwirfst,
lade immer zuerst `stilregeln.md` und wende alle Regeln an.

## Verwendung

```
/draft-reply [Kontext der Mail]
```

## Kontexte

- `gericht` — Richter:innen, Obergericht, Staatsanwaltschaft
- `mandant-formell` — neue oder formelle Mandanten
- `mandant-vertraut` — langjährige Mandanten (Vornamen-Basis)
- `kollegen-extern` — andere Anwälte (normal oder Konflikt)
- `intern` — Team MÜLLER PAPARIS AG

## Quellen

- `stilregeln.md` — destillierte Regeln v0.1.1
- `beispiele/` — echte E-Mail-Beispiele pro Kontext
